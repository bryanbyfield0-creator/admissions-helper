Download a copy before you clear the browser, switch computers, or change devices. Keep backups somewhere private. Imported files stay on this device only.

Privacy

  • This app runs only in your browser. There is no account and no server of ours that receives referrals.
  • Records are stored in this browser’s local storage. Clearing site data, using another browser, or using another device will not show the same list unless you restore a backup.
  • Referral PDFs (including scanned packets), Word files (.docx), text files, and photos of referrals are read on this device so the text can be suggested into the form. Scanned pages are read with text recognition (OCR) that runs on this device. The file itself is not saved, and it is not sent anywhere.
  • This is not connected to an EHR, payer portal, or insurance eligibility system. It does not score clinical fit or estimate reimbursement.
  • Prefer initials instead of a full name when that is enough for your work.

Diagnoses

Diagnoses are read only from the referral's diagnosis, problem list, medical history and assessment sections. A code is kept only if it is in the official ICD-10-CM code set (stored on this device), and the official description is shown. Diagnoses listed without a code stay uncoded; you can pick a code from the suggestions if you need one.

Allergies Safety

Allergies are read only from the referral's allergy section. NKDA (no known drug allergies) is different from a referral that does not mention allergies.
